# 认知工作区

认知工作区是可独立运行的本机对话服务，也可作为深圳湾日记的下属服务。此开源发行版只包含程序和运行说明，不附带任何用户对话、认知画像、调用记录或私人配置。首次运行时会创建全新的本地数据。

## 启动

使用 Python 3.12，无第三方 Python 依赖。在认知工作区项目根目录（本目录的上一级）运行：

```powershell
python cognitive_workspace/server.py
```

打开 <http://127.0.0.1:8766>，点击「新建工作区」。服务读取启动进程中的 `DEEPSEEK_API_KEY`，密钥不发给浏览器、不写调用日志。关闭终端将停止服务，重新运行同一命令即可恢复。

`.env.example` 说明所需环境变量，密钥默认留空。程序不自动加载 `.env` 文件；请在启动服务的终端或部署平台中设置该变量。PowerShell 示例：

```powershell
$env:DEEPSEEK_API_KEY = '替换为自己的 API 密钥'
python cognitive_workspace/server.py
```

未设置密钥时可以查看和管理本地工作区，发送消息时会提示配置密钥。通过日记本启动时，环境变量由日记服务进程传给本服务。

默认仅监听回环地址，端口为 8766。可用 `--port` 调整端口，用 `--data-dir` 指定独立的数据目录；默认目录是程序旁的 `data/`，不随启动时的工作目录改变。同一数据目录只允许一个服务进程。独立运行时采用本机单用户模式。

## 当前功能

- 系统自带唯一的空白「全局统筹」，永久置顶、暗金色标识，不可归档或删除。旧库升级仅新增此工作区，原有工作区和讨论保留。
- 全局统筹默认使用 Pro，自动模式也从 Pro 开始，可手动选择 Flash。长期角色覆盖生活、家庭、情感、关系与商业等领域，近期讨论目的可以转变。它先参考轻量目录，再按需只读查询摘要或原文。
- 工作区管理与流式聊天。消息保存在本机 SQLite；浏览器只保存未发送草稿与界面偏好。打开页面、切换工作区和浏览历史不调用模型。
- 普通工作区自动模式先用 Flash，复杂推演可请求 Pro，也可手动选择。Flash 使用非思考模式，Pro 使用低强度思考模式，API 标识为 `deepseek-flash` / `deepseek-v4-pro`。
- 最近约 15 轮对话、工作区摘要及共享认知组成上下文。原文已有事实直接使用，缺失时按需只读检索其他工作区或更早历史。
- 全局目录支持关键词和分页查询；跨区长消息可按每段 4000 字符续读，批量原文读取限制为 24000 字符。全局每轮最多 6 次模型调用，普通工作区最多 4 次，工具资料累计限制为 40000 字符。
- 实际对话后进行有界记忆整理，没有定时扫描。原始对话只追加，派生摘要保留版本；画像引用必须来自用户原文，明确偏好按核对后的原话写入。人工修改讨论目的不会被较旧后台任务覆盖。
- 失败时保留问题及部分回复，显式重试复用请求 ID。关闭浏览器不撤销服务端正在完成的回复，刷新后可恢复。
- 共享认知逐条校验：同 key、同内容合并来源；同 key 内容冲突或原话无法核对时跳过该项，保留已有认知，其余有效条目正常保存，并提示部分内容未更新。此流程没有付费自动重试。

历史检索目前使用关键词与分页。不同 key 间的语义冲突、长期画像容量和大量历史下的召回仍有局限。

## 目录与运行数据

```text
认知工作区/
├─ identity/service.json          稳定服务身份
└─ cognitive_workspace/
   ├─ server.py                  HTTP 服务与启动入口
   ├─ index.html                 页面
   ├─ app.js                     前端交互
   ├─ styles.css                 样式
   ├─ backend/                   对话、存储、模型与记忆逻辑
   ├─ README.md                  运行与部署说明
   ├─ .env.example               环境变量示例，不含密钥
   └─ data/                      首次运行后自动创建，不纳入源码
```

`data/workspace.sqlite3` 保存工作区、对话和认知数据。`data/calls/<调用ID>/` 保存逐次调用证据，包括原始请求、未改写的 SSE 字节流、实际模型、输入/缓存/输出 Token、时间戳、首段正文延迟、总耗时及费用估算。`data/users/` 保存网关下其他用户的独立数据。

发行版不包含 `data/`。首次运行只会生成空白「全局统筹」工作区，不会自动导入示例对话或外部数据库。迁移现有安装时应覆盖整个数据目录，并采用一致的 SQLite 备份方式；深圳湾日记现有 OSS 备份范围不自动包含认知工作区。数据目录、SQLite 的 `-wal` / `-shm` 边文件、运行锁、调用记录和密钥均不应提交到公开仓库。HTTP 服务不会公开数据或代码文件。

## 费用与预算

首段正文延迟排除工具准备性文本和模型思考，记录服务端端到端耗时，不包含浏览器绘制测量。后台记忆整理另有调用记录，侧栏累计费用包含这些调用。

默认按 UTC 月、以程序配置的高峰价估算上界，使用 **50 元/月** 预算限制新调用。未知用量保留预留额，不按零计费；实际账单可能更低。价格配置来源与核对日期保存在 `backend/provider.py` 中，使用前请按 [DeepSeek 官方价目表](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 自行核对。预算只覆盖当前数据目录，不包括其他软件或其他独立目录。

## 作为深圳湾日记子服务

层级为「主站主页 → 深圳湾日记（日记本管理服务）→ 认知工作区」。认知工作区的 HTTP 服务、页面、模型逻辑和用户数据保留在本项目；日记本负责子服务启动、登录会话、受控代理及入口导航。两种运行模式均不自动读取日记正文。

日记本登录后的主页面提供「认知工作区」入口；点击工作区左上角原有的蓝色聊天图标可返回日记本。返回地址仅使用网关下发的 `diary_url`；独立运行时图标没有链接，也不参与键盘 Tab 导航。

通过独立日记服务挂载在 `/cognitive/`，通过主站挂载在 `/shenzhen-bay-diary/cognitive/`，旧入口 `/diary/cognitive/` 兼容。页面静态文件和 API 随当前挂载目录解析。

日记管理器自动传入以下参数：

```powershell
python cognitive_workspace/server.py --host 127.0.0.1 --port 8766 --gateway-token-file <私密token文件>
```

`--gateway-token-file` 是纯 UTF-8 秘密文本，去除首尾空白后至少 32 字符；省略该参数使用独立模式。服务仅允许监听 `127.0.0.1` 或 `localhost`。

网关模式的所有业务请求必须同时携带有效的 `X-SZD-Gateway-Token`、规范的 `X-SZD-User: userN` 和路径前缀 `X-SZD-Prefix: /…/cognitive`。这些头由日记服务写入，浏览器不接触共享秘密，工作区也不接收日记登录 Cookie。写操作继续校验每位用户独立的 `X-Workspace-Token`，并拒绝跨站请求。

内部用户编号 `user0` 使用 `data/workspace.sqlite3` 与 `data/calls/`；其他用户分别保存在 `data/users/userN/workspace.sqlite3` 与 `data/users/userN/calls/`。编号仅用于数据隔离，不是预设注册账号。网关模式下账号注册和登录由日记本管理。每位用户独立维护 Store、Engine、调用日志、费用预算和 CSRF token；默认 50 元/月预算按每个用户数据目录计算。首次收到该用户的有效业务请求时才创建其数据。

浏览器草稿按挂载路径及 user_id 保存，取得后台身份后才读取；独立模式继续使用原界面偏好。网关下每 15 秒、恢复焦点及发送前验证日记会话；会话过期时禁用操作并返回登录页，切换账号时清空页面并重新载入。页面进入浏览器历史缓存时隐藏原视图，恢复时强制重载并重新验证身份。

稳定服务身份保存在 `../identity/service.json`，固定 ID 为 `urn:uuid:f3d45386-1d65-4a3b-a7c6-70d2826b89f7`。公开只读探测 `GET /__service__/identity` 返回 `identity_protocol=1`、`service_role=workspace`、`ready=true`。仅网关模式声明 `gateway-user-v1`，且持有正确部署秘密的探测请求才能得到 `gateway_authenticated=true`。身份请求不创建用户或修改业务数据；日记管理器据此拒绝误复用独立模式或另一部署的进程。
